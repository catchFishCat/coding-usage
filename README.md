# coding-usage

Unified quota/usage monitor for AI coding subscriptions and APIs.

## What it aims to solve

- Track mixed quota models in one place (rolling windows, monthly limits, budget, balance).
- Monitor many providers (OpenAI, Copilot, Gemini, Claude, OpenRouter, DeepSeek, SiliconFlow, Minimax, GLM, Kimi).
- Alert before exhaustion (desktop, webhook, email).
- Show usage trends for planning and allocation.
